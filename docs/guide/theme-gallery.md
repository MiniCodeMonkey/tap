# Theme Gallery

Tap ships `base` plus 20 designed themes. Each preview below is the same
deck rendered with that theme, so the differences you see are the theme's
own.

The fastest way to compare them is live: run `tap dev` on any deck and
press `t` to cycle every theme, or add `?theme=<slug>` to the URL to jump
straight to one. `tap theme list` prints the same list in the terminal, and
`tap theme show <slug>` prints a theme's tokens and illustration style.

## Dark Themes

| Theme | Preview | Built for |
|-------|---------|-----------|
| `terminal` | ![terminal](/images/themes/terminal.png) | Infrastructure and live-coding talks where the audience lives in a shell and the deck should feel like one long tmux session. |
| `blueprint` | ![blueprint](/images/themes/blueprint.png) | Architecture and systems talks where every slide is a sheet from the drawing set and the diagrams are the argument. |
| `keynote` | ![keynote](/images/themes/keynote.png) | A big-room launch talk where one idea at a time lands on a dark stage, lit from above. |
| `observatory` | ![observatory](/images/themes/observatory.png) | A data-heavy infrastructure talk, charted like a night sky: systems as bodies, readings taken through a reticle. |
| `arcade` | ![arcade](/images/themes/arcade.png) | A high-energy war-story talk framed as a game you can win, built to stay legible on a washed-out projector. |

::: tip Picking one
A bright room or a projector with poor black levels washes out a dark
theme. When in doubt, take a light one. Beyond that, match the "built for"
line to your actual talk rather than the look.
:::
